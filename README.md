# CS300_DSA_Analysis_and_Design
Portfolio item for CS300

CS 300 Portfolio Reflection

Throughout this course, I worked on projects involving data structures and algorithms to develop a program that could organize and retrieve information about college courses. The main goal was to create a system that could read course information from a file, display the courses in order, and allow users to look up individual courses and their prerequisites.

My approach involved comparing different data structures, including vectors, hash tables, and binary search trees, to determine which would work best for the program. This helped me understand why choosing the right data structure is important, since different approaches can affect how efficiently a program stores, searches for, and organizes information. I ultimately chose a binary search tree because it allowed the courses to be displayed in alphanumeric order without needing a separate sorting process.

One of the biggest challenges I encountered was learning how the different data structures worked and understanding when one might be more useful than another. Breaking the problems into smaller pieces, working through pseudocode, and testing my code helped me better understand the concepts and identify mistakes. I also became more comfortable troubleshooting problems rather than immediately assuming something was wrong with the entire program.

These projects expanded the way I approach software development by encouraging me to think more carefully about how a program should work before I begin writing code. I’ve learned that planning out the structure of a program and considering how information will be stored can make the development process much easier.

I’ve also developed a better understanding of the importance of writing code that is readable, maintainable, and adaptable. Using meaningful names, adding comments, and separating different tasks into functions makes it easier to understand what the code is doing and make changes later. Going forward, I want to continue applying these practices so that my programs are not only functional but also easier to improve and maintain.
